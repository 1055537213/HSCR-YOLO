# Mission: Explain the VisDrone Detection Project Clearly

## Why
Understand the core deep-learning mechanisms used in this repository well enough to explain design choices, training behavior, and tradeoffs accurately during an AI or computer-vision interview.

## Success looks like
- Explain CNN Backbone and DWConv using the YOLO11l and GSDR data path.
- Describe one SGD, AMP, and Mosaic training step without relying on buzzwords.
- Distinguish what each technique changes and what it does not prove about model accuracy.

## Constraints
- Use the current repository implementation and training parameters as the factual baseline.
- Prefer plain Chinese, concrete shapes, and VisDrone examples.

## Out of scope
- Deriving full backpropagation calculus or CUDA kernel implementation details.
