如何判断小目标漏检来自哪里

目标：区分“支持一个诊断假设”和“已经排除其他原因”，并准确说明当前 VisDrone 项目的证据强度。

当前可以成立的证据链

  1. 定性检查中，漏检集中出现在尺寸小、目标密集和遮挡明显的区域，提出空间细节不足的假设。
  2. 基线训练与验证曲线已经进入平台期，继续训练不再明显提高指标，说明问题不像单纯训练轮数不足。
  3. 640 输入的 YOLO11l 提升到 832 后，mAP50 从 0.38992 上升到 0.43294，说明保留更多输入细节对任务很重要。
  4. 加入 P2/HSCR 后，640 实验的 mAP50 从 0.38992 上升到 0.40748，mAP50-95 从 0.22922 上升到 0.23748；最低置信度附近的全类 Recall 约从 0.61 上升到 0.63。
  5. 验证数据、NMS IoU=0.7 和 max_det=300 没变，且 mAP 不是单一置信度点，因此结果支持“候选特征变好”，而不只是手动改了显示阈值。
结论边界：这些结果支持把特征表达不足列为主要优化方向，但还没有证明它是唯一或核心根因。历史实验存在 batch 和输入尺寸差异，仓库中也没有按目标尺寸统计 AP/Recall 或保存完整的 pre-NMS 候选召回分析。

四类原因怎样真正区分

可能原因应该看的证据当前状态
数据分布小/中/大框占比、类别频次、遮挡与截断分层指标同一数据集被控制，但尚未被排除
训练策略同结构下学习率、batch、增强和训练时长的单变量对照曲线已收敛，但没有完整策略消融
后处理pre-NMS Recall、conf/NMS IoU/max_det 扫描参数相同，尚未做系统扫描
特征表达固定其他条件后，P2只对小目标Recall/AP产生稳定提升已有总体指标支持，缺尺寸分桶与多种子确认

面试中的严谨表达

不要说“我已经证明核心原因就是特征表达不足”。更准确的是：“Bad Case 主要集中在小而密集的目标，基线曲线已经收敛；提高输入分辨率和引入 P2 后 Recall 与两项 mAP 同时提升，所以我将高分辨率特征表达不足确定为优先验证的主要假设。由于早期实验的 batch 不完全一致，我没有把它描述为唯一根因，后续继续用统一 640 设置、尺寸分桶和路由消融补齐证据。”
